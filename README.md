# hxyfront-62002 剧场灯光Cue表管理

源提示词编号：2

剧场灯光师使用的灯位与 Cue 表管理前端，支持演出名称、灯具编号、通道号、色片、焦点位置、亮度预设、Cue 触发顺序维护，含舞台平面灯位图、Cue 列表、当前场景预览、灯具筛选和演出版本备注，并内置**故障换灯闭环**。

## 故障换灯闭环

1. **报修**：灯具故障后，所有引用它的 Cue 自动进入「待替换」并持续显示待处理。
2. **替补判定（三条件同时满足）**：未参与该 Cue、色片相同、焦点同区；任一不满足即不合格。
3. **整次拒绝**：换灯弹窗为每个待处理灯位选择替补，只要一个不合格或未选，整批提交被拒绝，不改动任何灯位（拒绝同样写入维修记录）。
4. **结构不变**：换灯只切换灯位当前指向的灯具，灯位坐标、Cue 顺序、场景与亮度预设保持原样。
5. **维修记录**：原灯与替补灯各自保留维修记录（报修/接替/拒绝/维修完成/回切）。
6. **确认回切**：原灯维修完成后进入「已恢复·待确认」，必须人工确认才回切，替补灯具退场。
7. **同步与持久化**：待替换状态在 Cue 列表、筛选、舞台平面图、当前场景预览间同步；所有业务状态与筛选自动写入 localStorage，刷新保留，可导出 JSON 存档。

### 三模块划分

- `src/lighting/rules.ts` — 判定模块：Cue 状态派生、替补资格、整批校验、筛选、统计（纯函数）
- `src/lighting/store.ts` — 业务状态模块：报修/换灯/维修/回切动作、useSyncExternalStore、localStorage 存档
- `src/lighting/components.tsx` — 界面模块：舞台图、场景预览、Cue 列表、换灯弹窗、灯具档案与维修记录
